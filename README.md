# Alberto Alaniz - Data Analyst Portfolio

Personal portfolio website showcasing data analysis projects, certifications, and technical skills. Available in **Spanish** and **English**.

## Live Site

Open [this link]([url](https://devlearnsal.github.io/Data-Analyst-Portfolio/index-en.html)) in a browser, or deploy to GitHub Pages.

## Projects

| # | Project | Description | Tools |
|---|---------|-------------|-------|
| 1 | **Call Me Maybe** | Call center efficiency analysis with KPI tracking and operator performance metrics | Python, Pandas |
| 2 | **A/B Testing (Store)** | Conversion optimization through A/B testing on an e-commerce platform | Python, SciPy |
| 3 | **Ride Service** | Transportation service analysis — top taxi companies and neighborhood trip patterns | Python, SQL |
| 4 | **Ticket Store** | Marketing analysis for an event ticket platform — CAC, ROMI, and user retention | Python, Pandas |
| 5 | **A/B Test & Hypotheses** | Hypothesis prioritization and A/B test analysis for an online store | Python, SciPy |
| 6 | **Instacart** | Exploratory data analysis of Instacart grocery orders and customer behavior | Python, Pandas |
| 7 | **Book Analysis** | SQL-based analysis of a book publishing database | SQL |
| 8 | **Food Analysis** | A/A/B testing analysis for a food product startup's app funnel | Python, Plotly |
| 9 | **Predictive Model** | Customer churn prediction and clustering for a fitness center | Python, Scikit-learn |
| 10 | **YouTube Trends** | Interactive Tableau dashboard analyzing YouTube trending video patterns | Tableau |

## Tech Stack

- **Languages:** Python, SQL
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn, Plotly, Scikit-learn, SciPy
- **Visualization:** Tableau, Power BI
- **Web:** HTML, CSS, Bootstrap, jQuery
- **Other:** Git, Jupyter Notebook

## Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/DevLearnsAI/Data-Analyst-Portfolio.git
   ```
2. Open `index.html` in a browser.

For the contact form, a PHP-enabled server is required.
